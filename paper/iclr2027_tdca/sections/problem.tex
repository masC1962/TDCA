\section{Problem Formulation}

Given a question $q$, a corpus $\mathcal{D}$, an LLM $M$, and a resource budget $\mathbf{B}=(B_{\mathrm{call}},B_{\mathrm{tok}},B_{\mathrm{ret}})$, the system produces a terminal decision $y\in\{\textsc{Answer}(a),\textsc{Abstain},\textsc{BudgetExhausted}\}$. At step $t$, the controller observes a reasoning state $H_t$, chooses an operation--fidelity packet $p_t$, observes an outcome $o_t$, and applies a deterministic state transition:
\begin{equation}
  p_t=\pi(H_t,\mathbf{B}_t),\qquad H_{t+1}=T(H_t,p_t,o_t),\qquad \mathbf{B}_{t+1}=\mathbf{B}_t-\mathbf{c}(p_t,o_t).
\end{equation}
The goal is to maximize answer utility under resource constraints while satisfying safety invariants:
\begin{equation}
\max_{\pi}\;\mathbb{E}\!\left[U(y,q,H_T)\right]
\quad\text{s.t.}\quad \sum_{t<T}\mathbf{c}(p_t,o_t)\preceq\mathbf{B},\quad I(H_t)=1\;\;\forall t.
\end{equation}
Unlike a fixed-depth agent loop, both the selected action and termination time $T$ depend on the evolving graph.
