\section{Related Work}

\paragraph{Iterative and adaptive retrieval.}
IRCoT interleaves retrieval with chain-of-thought steps, establishing that later searches should depend on intermediate reasoning \citep{trivedi2023ircot}. Self-RAG learns reflection tokens to decide when to retrieve and critique generations \citep{asai2024selfrag}, while Adaptive-RAG selects among no-, single-, and multi-step retrieval using a learned complexity classifier \citep{jeong2024adaptiverag}. RAPTOR retrieves across a tree of recursively summarized passages \citep{sarthi2024raptor}. Superposition prompting processes document paths in parallel and prunes irrelevant paths without fine-tuning \citep{merth2024superposition}. \method{} differs by making allocation decisions repeatedly from an explicit, mutable reasoning state, and by jointly controlling operation type and fidelity without task-specific training.

\paragraph{Graph-structured retrieval and reasoning.}
RoG grounds relation-path plans in a knowledge graph \citep{luo2024rog}; Think-on-Graph lets an LLM interactively explore a knowledge graph \citep{sun2024think}; and G-Retriever retrieves a question-relevant subgraph for textual graph QA \citep{he2024gretriever}. HippoRAG combines a knowledge graph with Personalized PageRank for associative memory \citep{gutierrez2024hipporag}, and HippoRAG~2 strengthens passage integration and recognition memory \citep{gutierrez2025hipporag2}. These systems motivate structural retrieval, but their graphs primarily organize stored knowledge or retrieval. \method{} instead maintains a transient \emph{reasoning} hypergraph whose nodes include unresolved goals and derived claims; its edges affect both belief propagation and online resource allocation.

\paragraph{Test-time compute and self-correction.}
ReAct interleaves reasoning with external actions \citep{yao2023react}, self-consistency allocates parallel samples \citep{wang2023selfconsistency}, and Self-Refine iteratively improves outputs using model feedback \citep{madaan2023selfrefine}. Compute-optimal inference results show that the best test-time strategy depends on prompt difficulty \citep{snell2025scaling}. \method{} complements this line by treating multi-hop RAG as a sequential, partially observed allocation problem with explicit evidence dependencies, multiple resource currencies, and an abstention-aware stopping action.
